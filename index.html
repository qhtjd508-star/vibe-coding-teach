1. 바이브코딩 지도

아이디어가 서비스가 되기까지의 전체 과정입니다. 말로 요청하면 AI가 코드를 쓰고, 저장하고, 인터넷에 올리는 흐름을 한 장으로 봅니다.

바이브코딩은 말로 하는 코딩입니다. 만들고 싶은 것을 AI에게 설명하면, 코드는 AI가 씁니다.

프론트엔드의 세 가지 재료: HTML, CSS, 자바스크립트

같은 내용의 웹페이지를 세 가지 방법으로 만들었습니다. 하나씩 눌러서 무엇이 달라지는지 비교해 보세요.

① HTML만뼈대. 제목, 글, 목록, 버튼 같은 내용을 놓습니다. 버튼을 눌러도 아무 일도 없습니다.웹페이지 열기 ② HTML + CSS꾸미기. 색, 글씨, 간격, 모양을 입힙니다. 버튼은 아직 움직이지 않습니다.웹페이지 열기 ③ HTML + CSS + 자바스크립트움직임. 버튼을 누르면 숫자가 올라갑니다.웹페이지 열기

2. 간단한 게임 만들기

Gemini에서 캔버스(Canvas)를 켜고 아래 프롬프트 중 하나를 붙여넣으세요. 완성된 게임이 미리보기에 바로 나타납니다.

Gemini 열기

  1. 캔버스 켜기

    입력창의 도구 메뉴에서 Canvas를 선택합니다.

  2. 프롬프트 붙여넣기

    아래 카드에서 복사를 누르고 입력창에 붙여넣어 보냅니다.

  3. 미리보기에서 해 보기

    코드가 다 쓰이면 미리보기에서 게임을 직접 해 봅니다.

  4. 말로 고치기

    "배경을 하늘색으로 바꿔줘", "시간을 60초로 늘려줘"처럼 이어서 요청합니다.

두더지 잡기

예시 프롬프트 1
두더지 잡기 게임 웹앱을 만들어줘.

- HTML 파일 하나로 만들어줘. (CSS와 자바스크립트도 그 안에 포함)
- 3×3으로 구멍 9개를 배치해줘.
- 두더지(🐹)가 무작위 구멍에서 1초 정도 나왔다가 들어가.
- 두더지를 클릭하거나 터치하면 1점을 얻어.
- 제한 시간은 30초이고, 화면 위에 점수와 남은 시간을 보여줘.
- '시작' 버튼을 누르면 게임이 시작돼.
- 시간이 끝나면 최종 점수와 '다시 하기' 버튼을 보여줘.
- 밝고 귀여운 디자인으로, 휴대폰에서도 잘 보이게 해줘.

카드 짝 맞추기

예시 프롬프트 2
카드 짝 맞추기 게임 웹앱을 만들어줘.

- HTML 파일 하나로 만들어줘. (CSS와 자바스크립트도 그 안에 포함)
- 4×4로 카드 16장을 뒤집어 놓고, 과일 이모지 8쌍을 무작위로 섞어줘.
- 카드를 누르면 뒤집히고, 두 장이 같으면 그대로 열려 있어.
- 두 장이 다르면 1초 뒤에 다시 뒤집혀.
- 화면 위에 시도 횟수와 걸린 시간을 보여줘.
- 모든 짝을 맞추면 축하 메시지와 '다시 하기' 버튼을 보여줘.
- 깔끔한 디자인으로, 휴대폰에서도 잘 보이게 해줘.

1부터 25까지

예시 프롬프트 3
숫자 빨리 누르기 게임 웹앱을 만들어줘.

- HTML 파일 하나로 만들어줘. (CSS와 자바스크립트도 그 안에 포함)
- 5×5 칸에 1부터 25까지 숫자를 무작위로 배치해줘.
- 1부터 순서대로 눌러야 하고, 맞게 누른 칸은 색이 바뀌어.
- 틀린 숫자를 누르면 그 칸이 잠깐 빨갛게 변해.
- 첫 숫자를 누르면 타이머가 시작되고, 화면 위에 걸린 시간과 다음에 누를 숫자를 보여줘.
- 25까지 다 누르면 기록을 보여주고 '다시 하기' 버튼을 보여줘.
- 깔끔한 디자인으로, 휴대폰에서도 잘 보이게 해줘.

한 번에 안 돼도 괜찮아요. 교육용 Gemini는 한 번에 완벽하게 만들지 못할 수 있습니다. 안 되는 부분을 그대로 적어서 다시 요청하세요. 예: "시작 버튼을 눌러도 두더지가 안 나와. 고쳐줘."

구글 앱스크립트로 '학생 관찰 기록(누가기록)' 웹앱을 만들어 줘.
나는 코딩을 모르는 초등 담임교사야. 복사해서 붙여넣기만 하면 되도록 아래 조건을 정확히 지켜 줘.

[구조]
- 구글 시트에서 [확장 프로그램 > Apps Script]로 연 스크립트에 붙여넣을 거야.
- 파일은 딱 2개만 만들어 줘: Code.gs, Index.html (HTML 파일 이름은 대문자 I로 시작하는 Index)
- 시트는 SpreadsheetApp.getActiveSpreadsheet()로 연결하고, 시트 ID는 쓰지 마.
- 외부 라이브러리, 외부 이미지, CDN은 절대 쓰지 마.

[시트 구성]
- '학생명단' 시트: A열 번호, B열 이름. 내가 직접 입력할 거야.
- '누가기록' 시트: [기록 시각, 관찰 날짜, 번호, 이름, 영역, 관찰 내용]
- 두 시트가 없으면 자동으로 만들고 첫 줄에 제목을 넣을 것.

[Code.gs]
- doGet(): HtmlService.createHtmlOutputFromFile('Index')로 화면을 보여 줄 것. 제목은 '우리 반 누가기록'.
- getStudents(): '학생명단' 시트의 번호와 이름 목록을 돌려줄 것.
- saveRecord(record): '누가기록' 시트에 한 줄 추가할 것.
- getRecords(number): 해당 번호 학생의 기록을 최신순으로 돌려줄 것.

[Index.html]
- 위쪽 '기록하기' 영역
  - 관찰 날짜 (오늘 날짜가 기본값)
  - 학생 선택 (getStudents로 불러온 '번호. 이름' 목록)
  - 영역 버튼: 학습 / 생활 / 교우관계 / 진로 / 기타 중 하나 선택
  - 관찰 내용 입력칸 (여러 줄)
  - '저장' 버튼: google.script.run으로 saveRecord 호출. 저장 중에는 '저장 중...' 표시,
    성공하면 '저장했습니다'를 보여 주고 내용 칸만 비울 것. 실패하면 이유를 화면에 보여 줄 것.
- 아래쪽 '기록 보기' 영역
  - 학생을 고르면 getRecords로 그 학생의 기록을 날짜, 영역, 내용이 보이는 카드로 최신순 표시
  - 방금 저장한 학생의 기록은 바로 새로 고쳐서 보여 줄 것

[디자인]
- 교사가 쉬는 시간에 태블릿이나 휴대폰으로 빠르게 쓸 수 있게 큰 글씨, 큰 버튼, 차분한 색

[개인정보]
- 학생 기록은 개인정보이므로 웹앱 배포 시 '액세스 권한: 나만'으로 설정하는 방법을 안내해 줘.

[답변 형식]
1. Code.gs 전체 코드 (코드 블록 하나)
2. Index.html 전체 코드 (코드 블록 하나)
3. 학생명단 입력 방법, 코드 붙여넣는 방법, 웹앱 배포 방법을 번호 순서대로 아주 쉽게 설명
코드를 중간에 생략하지 말고 처음부터 끝까지 전부 써 줘.

A. 연결 테스트
AI에게 물어보기 · 질문과 답변 시트 저장

          
구글 앱스크립트(Google Apps Script)로 질문과 답변이 구글 시트에 자동 저장되는 'AI에게 물어보기' 웹앱을 만들어 줘.
나는 코딩을 모르는 교사야. 복사해서 붙여넣기만 하면 단번에 오류 없이 작동하도록 아래 조건을 글자 하나 틀리지 말고 정확히 지켜 줘.

[1. 파일 구조]
- 파일은 딱 2개: Code.gs, Index.html (HTML 파일 이름은 대문자 I로 시작하는 Index)
- doGet() 함수에서는 HtmlService.createHtmlOutputFromFile('Index').setTitle('AI에게 물어보기')를 반환할 것.
- 외부 라이브러리, CSS 프레임워크, CDN은 절대 쓰지 말고 순수 HTML/CSS/JS만 사용할 것.

[2. 권한 승인 및 시트 저장 조건 (Code.gs)]
- 맨 윗줄에 권한 승인 및 시트 확인용 함수인 authorize()를 만들 것:
  1) 내부에서 UrlFetchApp.fetch("https://www.google.com")을 호출할 것.
  2) getOrCreateSheet() 함수를 호출해 연결된 시트 주소(ss.getUrl())를 Logger.log로 출력할 것.
- getOrCreateSheet() 함수 작성 조건:
  1) SpreadsheetApp.getActiveSpreadsheet()가 있으면 그대로 반환할 것.
  2) 없으면(단독 앱스크립트 프로젝트면) PropertiesService.getScriptProperties().getProperty('SHEET_ID')를 확인해 열거나, 없을 경우 SpreadsheetApp.create('AI_질문답변_기록장')으로 새 시트를 만들고 그 ID를 SHEET_ID 속성에 저장한 뒤 반환할 것.
- saveToSheet(question, answer) 함수 작성 조건:
  1) 첫 번째 시트의 마지막 행이 0이면 ['일시', '질문 내용', 'AI 답변'] 헤더를 추가할 것.
  2) [new Date(), question, answer]를 appendRow로 기록할 것.

[3. AI 연결 조건 (Code.gs) - 반드시 이대로 작성할 것]
- askGemini(question = "안녕? 테스트 질문이야.") 처럼 기본값을 넣어 에디터에서 바로 실행해도 undefined 오류가 나지 않게 할 것.
- API 키는 PropertiesService.getScriptProperties().getProperty('GEMINI_API_KEY')로 가져오고 .trim() 처리할 것. 비어 있으면 '스크립트 속성에 GEMINI_API_KEY를 넣어 주세요.'를 반환할 것.
- UrlFetchApp.fetch로 아래 주소에 POST 요청을 보낼 것 (모델명 절대 변경 금지!):
  https://generativelanguage.googleapis.com/v1beta/models/gemini-3.5-flash-lite:generateContent
- 요청 옵션(options) 구조:
  1) method: 'post'
  2) contentType: 'application/json'
  3) headers: { 'x-goog-api-key': apiKey }
  4) payload: JSON.stringify({ contents: [{ parts: [{ text: question }] }] }) (temperature 등 다른 설정값은 일절 넣지 말 것)
  5) muteHttpExceptions: true
- 응답 처리:
  1) response.getResponseCode()가 200이 아니면 "오류 발생 (응답 코드: " + 응답코드 + ")\n" + response.getContentText()를 반환할 것.
  2) 응답코드가 200이면 JSON.parse(response.getContentText()) 후 data.candidates[0].content.parts[0].text 값을 꺼내서 saveToSheet(question, answer)로 시트에 저장한 뒤 답변을 반환할 것.

[4. 화면 구성 (Index.html)]
- 깔끔한 기본 스타일(CSS)을 <style> 태그로 넣고, 답변 표시 영역은 줄바꿈이 유지되도록 white-space: pre-wrap;을 적용할 것.
- 질문 입력칸(<textarea>), '물어보기' 버튼(<button>), 답변 표시 영역(<div>)을 만들 것.
- 버튼을 누르면 버튼을 비활성화(disabled)하고 '생각 중...'을 표시한 뒤 google.script.run.withSuccessHandler().withFailureHandler().askGemini(question)를 호출할 것.

[5. 답변 출력 형식]
1. Code.gs 전체 코드 (생략 절대 금지)
2. Index.html 전체 코드 (생략 절대 금지)
3. 초보 교사를 위한 따라하기 가이드 (순서대로 쉽게 설명):
   - Index.html 생성 시 '.html'을 빼고 'Index'만 입력해야 한다는 주의사항
   - 프로젝트 설정 -> 스크립트 속성에 GEMINI_API_KEY 넣는 법
   - 배포 전 상단에서 'authorize' 함수를 선택해 [실행]을 누르고 [권한 검토] -> [Advanced(고급)] -> [Go to ...(unsafe)] -> [Allow(허용)]를 눌러 외부 통신 및 시트 권한을 승인하는 방법과 하단 실행 로그에서 시트 주소 확인하는 법
   - 웹앱 배포 방법 및 코드 수정 시 [배포 관리] -> [새 버전]으로 업데이트하는 방법

        

        

          
B. 수업용 앱

[기능]
- 영어 단어나 표현을 입력하고 '만들기'를 누르면 AI가 아래를 만들어 줄 것
  1) 초등 6학년 수준의 쉬운 영어 예문 2개와 한국어 해석
  2) 그 단어로 4지선다 퀴즈 1문제와 정답
- AI에게는 반드시 JSON 형식으로만 답하라고 요청하고, Code.gs에서 JSON으로 읽어서 화면에 카드로 보여 줄 것.
- '시트에 저장' 버튼을 누르면 '예문모음' 시트에 [저장 시각, 단어, 예문1, 해석1, 예문2, 해석2, 퀴즈, 정답]을 한 줄 추가할 것.
  시트가 없으면 자동으로 만들고 첫 줄에 제목을 넣을 것.
- 시트는 SpreadsheetApp.getActiveSpreadsheet()로 연결할 것.
